How DJAY Bot works today

One account enters one tenant-scoped workspace, activates one or more bot families, publishes deployments, and handles every customer outcome through a shared Inbox, Contacts, Leads, Knowledge, Usage, and team layer.

Current-state warning: all six catalogue packages remain marked non-sellable in release requirements. FlowBot and TextBot are public preview; VoiceBot is pilot. This UI is a system map, not a claim that paid self-service GA is live.

1. IdentityUser/session is authenticated.
2. MembershipUser belongs to selected tenant.
3. PermissionRole allows the operation.
4. ContextTransaction sets app.tenant_id.
5. Forced RLSRows must match tenant context.

Tenant transaction

scoped

Sets tenant ID, user ID, membership ID, session ID and request ID inside a database transaction. Tenant repositories still include explicit tenant predicates as defense in depth.

Platform transaction

separate realm

Sets platform user and role instead of tenant context. Cross-tenant views use dedicated permissioned projections and audit, not a general tenant-API bypass.
