# Score-to-9.5+ Platform Excellence Program

> **Sequencing authority:** Use **[plan v2 amended](./2026-07-22-score-to-9.5-plan-v2-amended.md)** for gate order.  
> **Execution authority (ultra-detailed):** Use **[ULTRA Fix Plan](./2026-07-22-ULTRA-FIX-PLAN.md)** for file maps, schemas, interfaces, and step checklists.  
> This v1 file remains a supplementary task catalog; where conflict, **ULTRA > v2 > v1**.
>
> **For agentic workers:** Implement workstream-by-workstream. Prefer `subagent-driven-development` or `executing-plans` per workstream. Do not flip `sellable: true` until **G7** (and only after **G6b** pen-test per v2/ULTRA). Checkbox tasks track delivery.

**Goal:** Lift every multi-role score from the Jul 22, 2026 baseline to **≥ 9.5 / 10** (stretch **9.9**, aspirational **10**) for CTO, PM, Product Designer, Software Engineer, SQA, UI, UX, Merchant Admin, Staff/Agent, and Coding Agent synthesis — covering DJAY Bot SaaS plus prior-discovered defects in the root Voice app and FlowBot V1 reference.

**Architecture:** Keep SaaS isolation (realms, forced RLS, provider confidentiality, evidence-based readiness). Change the *product shape*: one sellable SKU first, Stripe-activated entitlements, linear onboarding wizard, role-based homes, collapsed studios, production E2E proof. Treat Platform pilot activate as escape hatch only. Fix root Voice V1 production bugs in parallel (CORS, booking race, quota, headers) so the portfolio is not secretly unsafe while SaaS improves.

**Tech Stack:** Existing — Node 24, pnpm, Next.js App Router, PostgreSQL 16 + forced RLS, Zod, Stripe, Vitest, Chromium QA scripts, voice/ai gateways. No new framework rewrites.

**Baseline scores (2026-07-22):** CTO 7.2 · PM 5.5 · Product 5.8 · SWE 7.0 · SQA 6.0 · UI 5.5 · UX 4.8 · Merchant 4.5 · Staff 5.2 · Agent 6.2

**Honesty rule:** Engineering alone cannot hit true **10/10**. Scores ≥ 9.5 require live evidence (named merchant journeys, Stripe, legal, pen-test lite, ops runbooks). Score **10** additionally needs sustained production metrics (uptime, incident MTTR, churn, support load) over time. This plan targets **≥ 9.5** with explicit **9.9/10** gates.

## Global Constraints

- Never trust browser-supplied tenant, role, plan, provider, or model IDs (`AGENTS.md`).
- Browser cannot mark onboarding ready; only server evidence + `{ action: "refresh" }`.
- Do not mark any package `sellable: true` until Gate G.
- FlowBot remains deterministic (no AI imports in FlowBot packages).
- Provider/model IDs never enter tenant/public DTOs.
- First GA SKU: **exactly one** of `flowbot_basic` or `ai_chat_basic` (decision locked in W0).
- Thai + English UI chrome required for tenant-web and public-site before Merchant/UX ≥ 9.5.
- Root Voice app production defects from prior audit are in-scope (W1).
- Prefer fixing over rewriting; split god files only when touching them for features.
