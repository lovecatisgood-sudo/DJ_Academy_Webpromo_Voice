## Normative interfaces (code expert contract)

### `purchase_intent` (W2.1 — before any checkout UI)

```text
Table: billing.purchase_intents  (or tenancy.purchase_intents — pick one schema, document in migration)
  id uuid PK
  tenant_id uuid NULL until verify completes, then NOT NULL
  registration_id uuid NULL  -- pre-verify
  plan_key text NOT NULL      -- catalogue key only; price never from browser
  plan_version_id uuid NULL   -- resolved server-side at checkout time
  status text NOT NULL        -- open | consumed | expired | canceled
  created_at / expires_at / consumed_at
RLS: tenant-scoped when tenant_id set; registration path system-only
API: never accepts price, entitlement, or provider fields from browser
```

TypeScript surface (illustrative):

```ts
createPurchaseIntent(input: { planKey: PlanKey; registrationId?: string; tenantId?: string }): Promise<{ intentId: string }>
resolvePurchaseIntentForCheckout(context: TenantContext, intentId: string): Promise<{ planVersionId: string; planKey: PlanKey }>
consumePurchaseIntent(intentId: string, checkoutIntentId: string): Promise<void>
```

Reuse existing `prepare_stripe_checkout` / webhook / `activatePilot` — do not fork billing.

### `withTenantMutation` (not Next middleware)

```ts
// apps/api/lib/tenant-mutation.ts
withTenantMutation(request: NextRequest, options: {
  permission: TenantPermission
  assurance?: "none" | "recent_auth" | "recent_mfa"
  rateLimit: { scope: string; limit: number; windowMs: number }
  bodySchema: ZodType
}, handler: (ctx: { context: TenantContext; body: T; requestId: string }) => Promise<Response>): Promise<Response>
```

Migrate by **allowlist** (checkout, subscriptions, deploy, privacy, team) before G2/G5 — not all 150 routes on day one.

### Commerce capability profile

When `commerce_enabled=false`: checkout routes return `checkout_unavailable`; workers must not require Stripe secrets.  
When `commerce_enabled=true`: only billing/checkout/webhook/portal paths + billing worker require Stripe; Flow/AI/Voice runtimes must still start without billing if those products are enabled without commerce (document in `container.ts` + Terraform).
